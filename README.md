# Corne Layouts

Keyboard mappings for use with Corne keyboars and [Vile](https://get.vial.today) firmware.

## Philosophy

### Layers

- ***First Layer:*** Basic QWERTY
- ***Second Layer:*** Programming, the keys most frequently used for programming and numeric operations
- ***Third Layer:*** Media keys. For handling all things media and keyboard functionality (like LEDs)
